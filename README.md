# HelloBeeJs

First experience with @ethersphere/bee-js

This is a small example how to write to and read from the swarm network using bee-js.

Prerequisites:

- Install Swarm desktop. Initially it will running as an ultra light node - only capable to read from the network.
- Upgrade the node to light node - this will let you to write data to the network. For this you will need a digital wallet - I recommend MeteMask for now - and fund with https://fund.ethswarm.org/
- After that you can run this app

Technotes:

- repo is using pnpm as package manager
- latest node (24 as writing)
- vite for React
